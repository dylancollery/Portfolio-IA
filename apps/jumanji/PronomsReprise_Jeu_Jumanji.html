📖 Mini-cours — Pronoms de reprise Score : 0
📌 Qu'est-ce qu'un pronom de reprise ?
Un pronom de reprise remplace un nom déjà mentionné dans le texte.
Ce nom déjà mentionné s'appelle l'antécédent.

Le pronom doit avoir le même genre (masc./fém.) et le même nombre (sing./plur.) que l'antécédent.
Le lion rugit. Il effraya tout le monde.
→ Il reprend le lion (masc. sing.)
⚡ Pronoms sujets
SingulierPluriel
Masculinilils
Fémininelleelles
Les dés roulèrent. Ils s'arrêtèrent sur le 5.
La boîte brilla. Elle s'ouvrit seule.
⚠️ Piège — groupe mixte
Un groupe avec fille + garçon → on utilise Ils (masculin l'emporte sur le féminin au pluriel).
Sarah et Peter coururent. Ils se cachèrent. ✅
Sarah et Peter coururent. Elles se cachèrent. ❌

🔁 Comment vérifier ?
Étape 1 — Trouve l'antécédent (le nom repris).
Étape 2 — Vérifie son genre et son nombre.
Étape 3 — Choisis le pronom qui correspond.

Les règles du jeu étaient complexes.
Antécédent : les règles → fém. plur.
→ pronom sujet : Elles ✅ (pas Ils ❌)
🧠 Astuce mémo
Genre : regarde le déterminant d'origine — le/un → il, la/une → elle.
Nombre : pluriel → ils ou elles.
COD ou COI ? Pose la question au verbe :
verbe + qui/quoi ? → COD (le/la/les)
verbe + à qui ? → COI (lui/leur)
