Salle 1 — Réacteur de Calcul
Le réacteur principal est hors service. Le code de redémarrage est un résultat à calculer. Sans lui, la station reste gelée.

Calcule le code de redémarrage :

47 × 8 − 32 = ?

Tape uniquement le nombre

Décompose en deux étapes : d'abord la multiplication, puis soustrais 32 du résultat.
Essaie de décomposer 47 : pense à (40 + 7). Multiplie chaque partie par 8 séparément puis additionne.
